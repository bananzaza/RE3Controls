# RE3Controls for Resident Evil 5（中文说明）

[English](README.md) | [简体中文](README.zh.md)


`xinput1_3.dll` 代理模组，为 **RE5 Gold Edition（Steam 1.2.0，32 位）** 提供自由相机、随时换肩、普通枪变焦、
动作中移动等能力。基于 *bananzaza* 的 RE3Controls 与 *notencio* 的 1.9.x 版本。

---

## 与原版游戏的差异

以下每一项都是与「未装模组的原版」的差异。不修改游戏文件，只需把 `xinput1_3.dll` 放到 `re5dx9.exe` 旁边。

### 相机与瞄准

| 本模组 | 原版 |
|---|---|
| **自由相机**：走路与瞄准时鼠标都能转视角，角色跟随 | 固定越肩视角，只能随角色转向 |
| **随时换肩**：键盘 **B**（`[Controls] ShoulderKey`，可改任意字母）或手柄 **RB**（`RunButton=RB` 时为 L3），掩体与行走中同样有效 | 没有换肩功能 |
| **普通枪变焦**：瞄准时 **F** 拉近、**C** 拉远（`[Zoom] ZoomFovStep=-20`，`ZoomMaxStep=3`） | 每把枪固定一个视野 |
| **开镜移动**：举着狙击镜/火箭筒也能走（`[Zoom] ScopeWalk=1`） | 开镜时角色被定住 |
| 瞄准俯仰继承自由相机，收镜后不会被拉回 | 俯仰由站姿固定 |
| 子弹沿**相机射线**飞行，含激光瞄准器 | 沿武器自身方向 |
| 体术使用**游戏自带的固定相机**（`[Camera] StockMeleeCamera=1`），动作更自然；持刀仍用模组相机 | 全部使用游戏相机 |

### 移动

| 本模组 | 原版 |
|---|---|
| **瞄准行走**：举枪或持刀时都能移动（`GunWalk=1`、`KnifeWalk=1`） | 瞄准时站定 |
| **移动中换弹 / 换枪**（`ReloadWalk=1`、`SwitchWalk=1`），也包括空仓时游戏自动换弹 | 两者都会让角色停下 |
| 收枪（`ReadyEnd`）与开火后仍可转向 | 这些动作期间方向被锁 |

### 武器

| 本模组 | 原版 |
|---|---|
| **开火后不卡枪**：单发武器与弹匣最后一发都能立刻恢复控制（模组把开火动作的等待计时器压住） | 开火后会僵在射击姿态一段时间 |
| **换枪不会自动举枪/自动换弹** | 换枪可能强制进入举枪态 |

### 刀

| 本模组 | 原版 |
|---|---|
| 挥刀可以转向，持刀可以走/跑（走的是通用瞄准行走路径） | 出刀后朝向与移动都被锁 |
| 持刀姿态更灵活 | 持刀即站定 |

### 输入健壮性（不会在错误时机触发）

| 本模组 | 原版 / 旧版本 |
|---|---|
| 体术、处决、被抓、翻越、攀爬、受击、脚本动作期间，**瞄准键与挥刀键全部无效**；由统一分类器 `aidc::Locked` 判定，**覆盖所有角色** | 模组会在这些动作中把角色转向相机、甚至拔刀 |
| **角色不会自行举枪**：只有玩家真的按瞄准时才写举枪位 | 旧版在投掷、受击后会强制举枪 |
| **被打后不会自动换弹或自动瞄准** | 旧版会把游戏锁存的按键继续送出 |
| 投掷完全交给游戏：角色站定，收势不抽搐 | 旧版与投掷动画互相干扰 |

## 已知引擎限制（不是模组 bug）

这些是引擎自身的行为，模组**不会**去绕过（尝试过，代价是更严重的回归）：

| 限制 | 原因与表现 | 玩家可做什么 |
|---|---|---|
| **快速挥刀、使用道具（急救喷雾等）时不能移动** | 动作开始时引擎执行 `0xB7A8F0`：`or [角色+0x2D7C], 0x80000000` 并清空移动向量，属于引擎的移动锁。清掉锁位只能恢复动画自带的前冲；模拟瞄准状态会改变方向判定与投掷动作 | 与**按住瞄准键**时一样操作即可移动（原版同样如此） |
| **狙击镜用的是游戏自带瞄准** | 镜内画面由武器相机绘制，模组能写的字段（射击点、瞄准点、手柄输入）都到不了它；每帧写瞄准状态会让镜内俯仰卡死 | 镜内按原版习惯瞄准；`ScopeWalk` 仍可开镜移动 |
| **激光瞄准器只在手柄路径出现** | 引擎只在手柄输入路径上绘制激光 | 键鼠玩家使用准星（`Crosshair`） |
| **五个钩子无法安装** | RE5Fix 已改写过这些入口（相机控制、绑定槽、相机射线、手柄瞄准、准星请求）。模组在没有它们的情况下工作：腿部层遮罩改在 `setMotion` 处施加 | 无需操作，功能不受影响 |

> 说明：以上为**引擎层面的既定行为**，属于设计取舍而非缺陷。模组的选择是「保持原版可玩性」，而不是用高风险手段强行改写。

## 配置速查

模组首次运行会在 DLL 旁生成带完整注释的 `RE3Controls.ini`。`Mode=MeleeCamera` 表示除体术相机外全部保持原版行为。

### [Controls]

| 键 | 默认 | 说明 |
|---|---|---|
| `Enabled` | `1` | 模组总开关（0 = 完全原版） |
| `Mode` | `Full` | `Full` 全部功能；`MeleeCamera` 仅体术相机 |
| `RemapButtons` | `1` | RE3 键位：A 交互、X 换弹、Back 地图、L3 跑、R3 相机复位、RB 换肩、LT 瞄准、LB 刀、RT 射击 |
| `InteractButton` | `A` | 交互提示键（`X` = 保持游戏原本的 X 提示） |
| `Run` | `Toggle` | 跑步方式：`Stock` 原版 / `Toggle` 切换 / `Hold` 按住 |
| `RunButton` | `RB` | `RB` 跑、L3 找同伴；`L3` 则相反 |
| `OneButtonReload` | `1` | 一键换弹 |
| `QuickTurn` | `1` | B + 后拉摇杆快速转身 |
| `WeskerDash` | `1` | 威斯克冲刺（R3 交给游戏） |
| `StickClicks` | `1` | R3+L3 挑衅；瞄准中 R3 交给游戏（RPG-7 夜视） |
| `KnifeFromAim` | `1` | 举枪时按 LB 直接出刀 |
| `InventoryMove` | `1` | 打开物品栏时仍可走/跑 |
| `ShoulderKey` | `B` | 键盘换肩键（A-Z 任意字母） |
| `CrosshairKey` | `T` | 键盘切换准星/激光 |

### [Camera]

| 键 | 默认 | 说明 |
|---|---|---|
| `FreeCamera` | `1` | 自由相机（右摇杆绕角色转，移动相对相机） |
| `Speed` | `180` | 相机水平转速（度/秒，摇杆满量） |
| `PitchSpeed` | `90` | 垂直转速 |
| `Distance` | `230` | 绕行相机到肩部枢轴的距离（cm） |
| `Height` | `150` | 枢轴高度（脚底起算） |
| `Shoulder` | `60` | 越肩横向偏移 |
| `DefaultPitch` | `8` | 默认俯仰（正 = 向下），R3 回到此值 |
| `AimDistance` | `100` | 瞄准时相机沿视线后移距离（0–200） |
| `FieldOfView` | `0` | 非瞄准时 FOV 增量（-15–40） |
| `AimFieldOfView` | `0` | 瞄准时 FOV 增量 |
| `InvertY` | `0` | 垂直反转 |
| `TurnSpeed` | `720` | 角色朝摇杆方向转身速度（度/秒） |
| `BackStep` | `0` | 后退时背对相机走 |
| `FollowPlatform` | `1` | 在转动平台上相机随平台转动 |
| `MeleeCamera` | `1` | 体术保持普通相机（无特写），右摇杆可转 |
| `GrabCamera` | `1` | 被抓保持普通相机 |
| `StockMeleeCamera` | `1` | 体术/攻击用游戏固定相机 |
| `AimCamera` | `0` | 实验：瞄准时保留模组相机 |
| `CoverShoulder` | `1` | 掩体中保持换肩选择 |
| `ShoulderSwapAlways` | `1` | 换肩键在非瞄准时也有效（刀仍在 LB） |

### [Aim]

| 键 | 默认 | 说明 |
|---|---|---|
| `AimPointFromCamera` | `0` | 由相机决定瞄准点 |
| `AimPointDistance` | `9999` | 瞄准点距离 |
| `AimPitchFromMouse` | `0` | 由鼠标决定瞄准俯仰 |
| `GunWalk` | `1` | 举枪时可走 |

| `ReloadWalk` | `1` | 换弹时可走 |

| `CrosshairSize` | `0.5` | 准星缩放（0.25–4） |
| `CrosshairKick` | `1` | 开火时准星张开 |
| `KnifeCrosshair` | `1` | 持刀时显示游戏准星 |

| `ShotgunSpread` | `1` | 霰弹扩散（0 = 全部弹丸同线） |

### [Movement]

| 键 | 默认 | 说明 |
|---|---|---|
| `MoveWalk` | `1` | 非瞄准时行走速度倍率（0.5–2） |
| `MoveRun` | `1` | 奔跑速度倍率 |

### [Visual]

| 键 | 默认 | 说明 |
|---|---|---|

### [Advanced]

| 键 | 默认 | 说明 |
|---|---|---|

### [Keyboard]

| 键 | 默认 | 说明 |
|---|---|---|

### [Coop]

| 键 | 默认 | 说明 |
|---|---|---|

| 键 | 默认 | 说明 |
|---|---|---|
| `ZoomKeys` | `1` | 普通枪变焦开关（F 拉近、C 拉远） |
| `ZoomFovStep` | `-20` | 每级 FOV 变化（负值 = 更近） |
| `ZoomMaxStep` | `3` | 最大级数（3 次约 -60°） |
| `ScopeLook` | `0` | 实验：镜内跟随鼠标（会卡住俯仰，默认关闭） |

## 安装与卸载

1. 把 `xinput1_3.dll` 放到 `re5dx9.exe` 同级目录；
2. 首次运行会生成 `RE3Controls.ini` 与 `RE3Controls.log`；
3. 卸载：删除 DLL（以及这两个文件）即可。

## 日志

`RE3Controls.log` 中会写入少量诊断行：`keyq:`（按键查询）、`fire:`（开火等待计时器）、`trace:`（收镜后的短采样），
以及排查用的 `dmg:` / `blendfail:` / `layerfail:`。它们都做了限流，可以忽略；自行编译时可去掉。
